# Домашнее задание Synergy

## Рекурсия и реализация стека на Python

В данной работе реализованы четыре задания:  

Факториал числа — рекурсивная функция **factorial(n)**, вычисляющая произведение чисел от `1` до `n`. Базовый случай — `n = 0` или `n = 1`.  

Сумма элементов списка — рекурсивная функция **list_sum(arr)**, последовательно складывающая элементы списка. Для пустого списка возвращается `0`.  

Бинарный поиск — рекурсивная функция **binary_search(arr, target)**, выполняющая поиск элемента в отсортированном списке. Возвращает индекс найденного элемента или `-1`.  

Стек — класс **Stack**, реализующий основные операции:  

1. **push()** — добавление элемента.

2. **pop()** — удаление последнего элемента.

3. **peek()** — просмотр последнего элемента.

4. **is_empty()** — проверка стека на пустоту.
